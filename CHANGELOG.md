# Changelog

Notable project milestones are recorded here. This is a learning-project changelog, not a guarantee of production support.

## [1.0.0] - Initial complete release

- Added object-oriented customer, savings-account, current-account, and transaction models.
- Added customer/account management, deposits, withdrawals, transaction history, and transfers.
- Added SQLite persistence, repositories, schema initialization, and transactional operations.
- Added customer registration/login, PBKDF2-HMAC-SHA256 password hashing, sessions, password changes, and ownership checks.
- Added an interactive terminal interface.
- Added bounded password-hash verification, temporary login throttling, stronger monetary validation, and expanded automated tests.
- Added project setup, architecture, testing, security, and educational-use documentation.
